# Script — The Claim That Is Not a Lock

**Target length:** ~52 seconds  
**Format:** vertical short, 9:16

**0:00–0:05 — Hook**  
The fastest way to waste a bounty week is not bad code. It is building the exact thing somebody else is already building.

**0:05–0:17 — Why the claim exists**  
RustChain's contributor guide documents one bounty that was submitted five times. Four pull requests created the same file, and three contributors had useful work closed as duplicates.

**0:17–0:31 — The mechanism**  
Before starting, comment `/claim` on the bounty issue. The claim lasts seven days and then lapses automatically. If you need more time, comment `/claim` again to renew it.

**0:31–0:43 — The important catch**  
A claim is a courtesy signal, not a payment lock. It tells other contributors the task is being worked on, but it does not reserve the reward.

**0:43–0:52 — Close**  
So the workflow is simple: check the issue, claim it, verify the real files and API, then build. One comment can save a duplicate week.
